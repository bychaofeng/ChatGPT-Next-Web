## 已被后续讨论调整的假设

1. v0.1 的“暂按单人使用”是早期验证范围，不是产品只能给一个人用。当前方向是同一套通用系统、未知用户直接起步、多学习者记录隔离和动态适配；不要求事先向开发者提交背景。
2. Room/Compose 是曾讨论的架构选项。v0.3 为验证训练行为，采用本地快照及Android平台View。完整数据库迁移和复杂状态机尚不能视作完成。
3. v0.2 中输入预算70%的摘要条件与当前16,000字符的简化阈值不同。六轮、三天、七天均是试用参数，不是已证实的教育规律。
4. v0.2提到的Python运行器、schema、request_examples及requirements属于当时单独的提示词包。本目录归档的是说明文档及其完整提示词附录，不声称这些旧包文件都安装到了安卓项目。
5. 旧版中“没有安卓界面/数据库/网络发送器”的描述限定在该版本包，不代表后续原型完全没有相应代码。当前代码和验证状态见[开发路线](../ROADMAP_AND_ACCEPTANCE.md)。
