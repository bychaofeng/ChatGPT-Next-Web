# 方案规划入口

整理日期：2026-10-02。本文档目录保存产品目标、训练设计、架构约定和开发路线，不是新的 APP 发布，也不表示所有规划均已实现。

**核心定位：一套通用的运动康复学习工具，通过每个人的实际作答动态适配；不是给某一位朋友手工定制的软件。新用户不用填写背景表，系统从未知状态开始。**

## 版本关系

产品方向以本目录整理后的方案为准；实际运行行为以相应提交的源码和测试记录为准。两者不一致的地方必须登记为差距，不通过修改文案假装已实现。

`archive/` 保留早期讨论形成的设计快照。它们不是 v0.3 运行时 API 契约，也不是可直接导入的正式题库；其中“暂按单人试用”的范围假设已被“同一系统支持不同用户的自动适配”取代。

当前四组运行时提示词在 [Prompts.kt](../../core/src/main/kotlin/cn/rehab/trainer/core/Prompts.kt)，实际请求及校验在 [Ai.kt](../../core/src/main/kotlin/cn/rehab/trainer/core/Ai.kt)。不要把历史 v0.2 JSON 字段直接发送给 v0.3 接口。
